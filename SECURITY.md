# Security Policy

| Version | Supported          |
|---------|--------------------|
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `awesome-octave-robotics` seriously. If you discover a
security vulnerability, please report it responsibly.

### Preferred channels (in order)

1. **GitHub Private Vulnerability Reporting** — use the "Report a security
   vulnerability" button on the repository (advisories). This is the preferred
   channel and keeps the report confidential until a fix is released.
2. **Email** — `f.s.farimani@gmail.com`

Please include:
* A clear description of the vulnerability and its impact
* Steps to reproduce (Octave commands, input files, scripts)
* The affected version(s) / commit(s)
* Any suggested fix or mitigation (optional)

### What to expect

* You will receive an acknowledgment within 5 business days.
* We will keep you informed of progress toward a fix and planned disclosure.
* We coordinate disclosure through GitHub Security Advisories; public
  discussion is avoided until a fix is available.

### Policy

* Please do not submit issues or pull requests that disclose a vulnerability
  publicly before we have had a reasonable time to address it.
* Do not access or modify data that does not belong to you.
* We will not bring legal action against researchers who follow this policy.

### Note

This project is a clean-room GNU Octave implementation and is **not**
affiliated with MathWorks. Security reports must **not** be sent to
`security@mathworks.com`; use the channels above instead.
